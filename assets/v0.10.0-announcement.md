## v0.10.0 released — ArkTS `.ets` & Reliable Code Context / ArkTS 支持已上线

**EN** — Working on a HarmonyOS project in DSH? [dsh-code-index v0.10.0](https://github.com/lemonxiny55/dsh-code-index/releases/tag/v0.10.0) now indexes ArkTS `.ets` files with a dedicated parser, including ArkUI component structs, methods, fields and decorators.

Find component definitions with file/line locations, explore statically identifiable ETS/TS references, and ask `code_context` for actual component source plus related business logic within a strict character budget. Partial or failed parses produce bounded diagnostics; weak relationships retain their provenance.

The installed stable package was verified with a real DSH Desktop Agent; Node 22/24 tests, builds and package-consumer checks passed. This is syntax and static code-context support: **no full HarmonyOS SDK semantics, HAR/module-alias resolution, state-update or UI rerender graph**.

**中文** — 在 DSH 中处理鸿蒙工程时，Agent 现在可以索引 ArkTS `.ets`：通过独立 parser 提取 ArkUI 组件 struct、方法、字段和装饰器，定位到准确的文件与行号。

可以搜索组件、查看静态可确定的 ETS/TS 引用，并通过 `code_context` 在严格字符预算内获取组件源码及相关业务逻辑。部分解析或解析失败会提供有限诊断，弱关系不会被包装成确定关系。

稳定安装包已通过真实 DSH Desktop Agent 验证，以及 Node 22/24 测试、构建和安装包检查。支持范围是语法与静态代码上下文，**不包含完整 SDK 语义、HAR/模块别名解析、状态更新或 UI 重渲染调用图**。

**Install / 安装** — Node 22/24 and a matching DSH `0.2.0-rc.2` host group / 匹配的 DSH 宿主版本组：

```sh
npx @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web add dsh-code-index@0.10.0
npx @deepseek-ai/dsh@0.2.0-rc.2 web
```

Try asking: “Use `code_context` to explain the component in `Index.ets` and its related business functions.” / 可以试着问：“用 `code_context` 解释 `Index.ets` 中的组件及相关业务函数。”
